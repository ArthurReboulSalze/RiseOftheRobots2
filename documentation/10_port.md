# 10 — C++ port status and next steps

The port is a native C++/SDL2 application using assets generated by the import pipeline. It needs a user-supplied original game copy; no game data belongs in Git.

## Build and layout

The verified Windows toolchain is Visual Studio 2022 / MSVC 14.44, CMake, SDL2 2.30.11, SDL2_image 2.8.4, SDL2_mixer 2.8.0, and nlohmann/json 3.11.3. `TOOLS/bootstrap_port.py` downloads official pinned dependency archives and checks their SHA-256. See the root README for the current commands. `PORT/CMakeLists.txt` builds the executable and copies required DLLs. `--assets` selects an imported asset profile.

The main source modules are `main.cpp`, `frontend.*` for menu flow, `ui.*` for rendering, `assets.*` for manifests and images, and `fighter.*` for fighter state. `PORT/tests` contains asset and fighter checks.

## Current playable slice

The frontend shows the decoded `LLOGO` images, the `MAINSCR` title image, and `VSFACE` portraits. It lists 28 robots for the original copy or 30 for Director's Cut Disc 1. The two extra Director's Cut robots are `RBT2` (SHEEPMAN) and `RBT3` (BUNNYRABBIT). Their own palettes work, although matching `RB42/RB43` and `AG2/AG3` assets are absent. Selection loads each fighter's RBT atlas, MVS movement bank, and CL2 collision data.

The window defaults to 1280×800 with a 640×400 logical surface. The original high-resolution RBT sprites are the primary mode; extracted RB4 low-resolution assets exist but the optional VGA mode is not wired up. Rendering uses vertical sync. The simulation currently advances at approximately 15 Hz, based on user visual testing of the too-fast initial loop; exact DOS pacing and per-animation timing still need to be measured. The first prototype ran at about 60 Hz and caused repeated, vibrating directional animations. That bug was fixed; the user confirmed the result works, while button mapping remains provisional.

An MVS image index `i` selects `atlas.frames[i+1]` because an RBT atlas begins with an empty entry. The corresponding collision frame is `CL2.records[i]`. Sequence-end markers are never rendered. Sprite placement uses the stored canvas origin, and the second fighter mirrors correctly. The fighter loop handles idle and directional transitions, provisional attack actions, CL2 box checks, 120-HP health, a 24-point super meter, and hit flash. A successful fighter regression test does not replace comparison with the DOS game.

The input model currently distinguishes forward/back relative to facing; MVS walk movements 8 and 9 use masks 0x01 and 0x20. RBT0 movement data is empty for some walk states, while `FUN_21baf` applies displacement from other states. Exact keyboard-to-mask mapping, run/walk speed, and state transition timing remain open. Collision box coordinates scale x by four and y by two; the current ground anchor is near y=312 and the standing center reference near x=294. These placements require visual validation.

## Video and menu limitations

The original supplied copy has only three ANI files: 39 LLOGO frames, 61 END frames, and 61 ENL frames. The importer now also detects 105 ANI files on Director's Cut Disc 1. The 102 additional streams are retained but not yet decoded. The number of frames alone does not determine playback duration because the DOS player uses timing commands. Font rendering, transition timing, menu composition, and the full selection screen are provisional.

## Immediate work

1. Decode the Director's Cut ANI streams and player timing, then integrate the complete intro and menu flow.
2. Map physical controls and movement masks against `RISE2.CFG` and DOS play. For example, mask 0x10 leads to movement 7, but its real attack key and reach need validation; at an initial separation of 200 pixels a 98-pixel reach would miss by roughly 40 pixels.
3. Add a box-visualization toggle (for example F1) and compare CL2 hit, hurt, and push boxes with the original. The port now re-arms a hit on a move change rather than every simulation frame; compare the exact DOS rule.
4. Complete hitstun, knockdowns, KO, timer, round transition, and camera clamping (`DAT_65fd6/65fda`).
5. The port now loads importer-generated 11,025 Hz MRW WAVs and lets SDL_mixer convert them to its output format. Complete source-faithful MRS timing/pitch and integrate the digital MGA–MGF fallback.
6. Render arena GGF backgrounds, ANR animation, CTL scrolling, original fonts, and then AI.

Damage tests suggest ordinary hits around 6–10 HP, or 12–20 hits from 120 HP, but the exact formula and defensive-state adjustments are documented in page 08. The Director's Cut profile will be the source for future complete content work once its extra ANI files are decoded.

## Verification and scope

The existing Release build, `fighter_frames`, and asset smoke checks passed with the 28- and 30-robot profiles. All 30 MVS banks were regenerated after the four descriptor flag bytes and displacement boundaries were corrected; 8,640 sequences and the old 28 atlas/CL2 mappings were checked. The 1,199 empty ANR frames are valid and must remain empty. These are structural checks; final animation speed, feel, sound/music, and visuals still need direct DOS comparison and user playtesting.
